### 1. 🧮 Python Calculator

A simple command-line calculator built with Python.

The calculator allows users to perform basic mathematical operations by entering two numbers and selecting an operation.

#### ✨ Features

* Addition
* Subtraction
* Multiplication
* Division
* User-friendly command-line interface
* Handles basic invalid input
* Prevents division by zero
* Allows repeated calculations

#### 🛠️ Concepts Used

* Variables
* `input()`
* `if`, `elif`, and `else`
* Arithmetic operators
* Loops
* Functions
* Type conversion
* Basic error handling

#### ▶️ How to Run

Make sure Python is installed on your computer.

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/my-python-projects.git
```

Navigate to the project folder:

```bash
cd my-python-projects
```

Run the calculator:

```bash
python calculator.py
```

# 2. 🔐 Python Password Guessing Game

A fun Python-based guessing game where the player tries to guess a predefined password.

The program repeatedly asks the user to enter a password and provides feedback until the correct password is guessed.

> **Note:** This is an educational guessing game. It does not attempt to break or access real accounts, systems, or passwords.

## ✨ Features

* Password guessing gameplay
* Repeated attempts
* User input
* Feedback after each attempt
* Attempt tracking
* Success message when the password is guessed
* Simple command-line interface

## 🛠️ Concepts Used

This project helped me practice:

* Variables
* Strings
* `input()`
* `while` loops
* Conditional statements
* Comparison operators
* Counters
* Boolean logic
* User interaction
* Basic program flow

## ▶️ How to Run

From the repository directory, run:

```bash
python password_guessing_game.py
```

Follow the instructions displayed in the terminal and try to guess the password.
